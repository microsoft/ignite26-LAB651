# Source

This folder contains the lab materials required to complete Lab 651: Build AI Agents in Teams 

The src folder contains the following: 

- helper_scripts: 4 PowerShell scripts designed to help you enable sideloading in your tenant, hydrate your tenant with data necessary for the lab, enable devPreview for your tenant if you are testing HTML widgets
- src: Contains all the business logic and environmental files for your agent. Review this to learn more about the Zava-Desk-Agents implementation
- Zava-mcp: Contains the MCP server that ran locally on the lab envrionmennt so you can recreate the same experience on your machine.
